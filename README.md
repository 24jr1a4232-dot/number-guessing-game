# 🎯 Random Number Guessing Game

A simple Python game where the computer generates a random number, and the player tries to guess it. After each guess, the program provides hints to help the player find the correct number.

## 📌 Features

* Generates a random number automatically.
* Accepts user input for guesses.
* Gives hints:

  * 📉 Too Low
  * 📈 Too High
* Congratulates the player when the correct number is guessed.
* Displays the number of attempts taken.

## 🛠️ Technologies Used

* Python 3
* `random` module

## 🚀 How to Run
